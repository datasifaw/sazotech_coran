SAZOTECH CORAN - ETAPE 2 / CORRECTIF AUDIO
========================================

Ce ZIP contient des fichiers complets pour ton projet Flutter existant.
Ne cree PAS un nouveau projet et ne modifie rien a la main.

1. Arrete flutter run dans VS Code (q).
2. Extrait ce ZIP dans C:\sazotech_coran avec -Force :
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\SAZOTECH_Coran_Etape2_CORRECTIF_AUDIO.zip" -DestinationPath "C:\sazotech_coran" -Force
3. Execute le script qui garantit la permission INTERNET :
   powershell -NoProfile -ExecutionPolicy Bypass -File "C:\sazotech_coran\installer_audio.ps1"
4. Execute :
   cd C:\sazotech_coran
   flutter pub get
   flutter run -d emulator-5554
