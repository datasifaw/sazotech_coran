INSTALLATION - WINDOWS 11
1. Dans le terminal flutter run, taper q si la session est active.
2. Télécharger SAZOTECH_Coran_Etape6_BIBLIOTHEQUE.zip dans Téléchargements.
3. Copier/coller dans PowerShell :
   Expand-Archive -LiteralPath "$env:USERPROFILE\Downloads\SAZOTECH_Coran_Etape6_BIBLIOTHEQUE.zip" -DestinationPath "C:\sazotech_coran" -Force
4. Ne pas relancer flutter create ni flutter clean.
5. Pixel 7 doit être démarré, une seule fenêtre, et apparaître avec flutter devices.
6. Commandes :
   cd C:\sazotech_coran
   flutter pub get
   flutter run -d emulator-5554
